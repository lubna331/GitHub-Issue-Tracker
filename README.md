# GitHub-Issue-Tracker
## 1️⃣ What is the difference between var, let, and const?
#### Ans : The difference between var, let, and const are their scope and reassignability. 'Var' is accessible, can be updated and redeclared within the function. 'Let' has scope througout the block and can be updated but can not be redeclared. 'Const' also has block scope but can not be updated or redeclared.

## 2️⃣ What is the spread operator (...)?
#### Ans : Spread operator (...) merges two arrays into a new single array without changing the original array.

## 3️⃣ What is the difference between map(), filter(), and forEach()?
#### Ans : map(), it changes data of the array and returns the new array of same length without changing original array. filter(), it returns selected data that meets the condition. forEach(), it goes through an array and performs an action for every item.
